# Política de seguridad

Para comunicar una vulnerabilidad, abre un aviso privado en GitHub o contacta
con los mantenedores antes de publicar detalles explotables.

Incluye la versión afectada, el entorno, los pasos mínimos para reproducirla y
el impacto observado. No incluyas credenciales ni datos personales.

Las comprobaciones live usan un navegador contra un sitio externo únicamente
cuando el usuario las solicita mediante `--check-updates`, `--live` o la tool
correspondiente.
