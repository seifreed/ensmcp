# Data packs

Cada JSON es independiente del paquete Python y declara schema, versión, vigencia, cobertura, autoridad y fuente. Se cargan con `ENSMCP_DATA_PACKS`.

- `iso27001.json`: selección parcial de correspondencias oficiales de la CCN-STIC 825.
- `dora.json`: relaciones editoriales parciales con artículos de DORA; no son equivalencias jurídicas.
- `nis2.json`: manifiesto inactivo y sin correspondencias porque el CCN retiró la CCN-STIC 892 anterior.

Un pack parcial no demuestra cumplimiento del marco externo. La fecha `reviewed_at` exige revisar sus fuentes antes de actualizarlo.
